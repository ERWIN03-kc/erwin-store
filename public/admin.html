Password admin

Password diatur lewat variabel ADMIN_PASSWORD saat server dijalankan. Ubah di sana, lalu restart server.

Chatbot tanya-jawab

Widget chat di pojok kanan bawah web pembeli dijawab otomatis pakai AI Groq, berdasarkan daftar produk yang aktif. Aktifkan dengan mengisi variabel GROQ_API_KEY saat menjalankan server (ambil kunci gratis di console.groq.com), lalu restart server. Kalau belum diisi, chatbot akan menampilkan pesan bahwa fitur belum aktif.
